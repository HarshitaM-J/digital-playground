A quick recap before you play. These are the pieces you’ll need.

01

Give the AI a brief, not a mystery.

Tell it who the site is for, what it should do and how it should look. “A course journal for classmates, with session tabs and quizzes” is a stronger starting point than “make it cool.”

02

Meet the three-player team.

HTML adds words and structure. CSS handles colours, fonts and spacing. JavaScript responds to clicks. Different jobs, one working website.

03

Built it? Give it a place online.

Build and test your files. Save them to GitHub for version history. Connect that repository to Vercel, deploy, then check the public link. That’s your launch sequence.

Bonus knowledge: the save point.
An account identifies you; a shared database stores your progress. Together, they can restore it on another device. Browser-only storage stays in that browser.
